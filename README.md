# Бей в голову!

Аркадные сражения машинок на арене. Свой код и своя графика: все спрайты генерируются кодом (`src/gfx`), чужие ассеты не используются.

## Запуск

```bash
npm install
npm run dev     # http://localhost:5173
npm test        # тесты физики (node:test)
npm run build
```

Управление: **A** — назад, **D** — вперёд, **R** — заново, **B** — показать физические фигуры.
На телефоне: левая половина экрана — назад, правая — вперёд.

## Как устроено

- `src/game/` — физика на [planck.js](https://github.com/piqnt/planck.js) (порт Box2D), без DOM.
  - `cars.js` — описания машин: корпус, колёса (подвеска, ведущие или нет), мотор (момент, макс. скорость, тормоз), подкрутка в воздухе, голова, пиксель-арт.
  - `car.js` — сборка машины: колёса на `WheelJoint` с моторами, голова на мягком `WeldJoint` (болтается на «шее»). Газ в воздухе крутит корпус.
  - `arena.js` — форма арены (SDF + контур для коллизий).
  - `game.js` — мир, контакты (колёса на земле, удар головой), шаг физики 1/120 с.
- `src/gfx/` — генерация пиксель-арта (`pixelart.js`), текстура арены, отрисовка.

Если голова касается арены — «БАЦ!» и перезапуск.
