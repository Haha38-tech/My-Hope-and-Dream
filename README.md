# Бей в голову!

Аркадные сражения машинок на арене. Свой код и своя графика: все спрайты генерируются кодом (`src/gfx`), чужие ассеты не используются.

## Запуск

```bash
npm install
npm run dev     # http://localhost:5173
npm test        # тесты физики (node:test)
npm run build
```

Управление: **A** — назад, **D** — вперёд, **R** — заново, **E** — редактор (арена, машина, размер), **B** — показать физические фигуры.
На телефоне: левая половина экрана — назад, правая — вперёд.

## Как устроено

- `src/game/` — физика на [planck.js](https://github.com/piqnt/planck.js) (порт Box2D), без DOM.
  - `cars.js` — три машины (Багги, Пикап, Монстр): корпус, колёса (подвеска, ведущие или нет), мотор (момент, макс. скорость, тормоз), подкрутка в воздухе, голова, пиксель-арт.
  - `car.js` — сборка машины: колёса на `WheelJoint` с моторами, голова на мягком `WeldJoint` (болтается на «шее»). Газ в воздухе крутит корпус.
  - `arena.js` — три арены (Стадион, Пончик, Яма): SDF + контуры для коллизий.
  - `game.js` — мир, низкая гравитация, сцепление шин со стенами (растёт со скоростью — на разгоне можно проехать потолок), контакты, шаг 1/120 с.
- `src/gfx/` — генерация пиксель-арта (`pixelart.js`), текстура арены, отрисовка.

Если голова касается арены — «БАЦ!» и перезапуск.
- `src/editor.js` — редактор по клавише E; выбор сохраняется в localStorage. Размер машины — 50–100% (только уменьшение).
